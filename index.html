Политика конфиденциальности — BLACK OWL Dark Theme for Ozon Seller

Редакция: 11 сентября 2026 года. Применяется к версии расширения 0.2.0. Разработчик: BLACK OWL Tech.

Назначение

Расширение добавляет тёмное оформление страниц кабинета https://seller.ozon.ru/app и https://seller.ozon.ru/app/*. Это независимый продукт BLACK OWL Tech, не связанный с Ozon, не одобренный и не выпущенный Ozon.

Что обрабатывается в браузере

Для изменения цветов расширение локально проверяет элементы открытой страницы, их CSS-стили, размеры, атрибуты, SVG и текстовые узлы. Текст используется для распознавания участков интерфейса, которым нужна докраска. На странице могут отображаться товары, цены, заказы и финансовые показатели; расширение не формирует из них выгрузки, не сохраняет их в своём хранилище и не передаёт разработчику.

Текущий URL используется для проверки области действия и повторного применения оформления при переходе между разделами Seller. История посещений не записывается. Расширение не читает cookies, пароли, токены авторизации или хранилища сайта, не обращается к API Ozon и не меняет цены, заказы или настройки продавца.

Какие настройки сохраняются

В хранилище расширения Chrome сохраняются только:

  • mode: тёмная тема, системная тема или выключено;
  • adaptivePatch: включена ли дополнительная докраска;
  • launcherVisible: показывать ли кнопку темы в кабинете.

Отдельно, только в локальном хранилище chrome.storage.local, сохраняется privacyConsentVersion — версия явно принятого согласия. Этот флаг не записывается в Chrome Sync и не переносит согласие на другие устройства.

Основное хранилище трёх настроек оформления — chrome.storage.sync. При недоступности этого API код темы и страниц управления использует chrome.storage.local. Когда пользователь включил синхронизацию Chrome, эти настройки могут передаваться инфраструктуре Chrome/Google и синхронизироваться между браузерами этого пользователя. При выключенной синхронизации Chrome хранит их локально. Содержимое кабинета в это хранилище не записывается. BLACK OWL Tech не получает копию настроек. Как работает Chrome Storage.

Передача данных и внешние страницы

В коде расширения нет собственной телеметрии, рекламных SDK, фоновой отправки содержимого кабинета или загрузки удалённых исполняемых скриптов.

Ссылки на сайт BLACK OWL Tech открываются после нажатия пользователем. После удаления расширения Chrome также может открыть страницу BLACK OWL Tech, зарегистрированную через setUninstallURL. Эти ссылки содержат постоянные UTM-метки источника перехода, но не идентификатор продавца, содержимое страницы, настройки расширения или индивидуальный идентификатор установки.

При открытии внешнего сайта браузер делает обычный веб-запрос. Сайт и его инфраструктура могут получать стандартные технические сведения, например IP-адрес и параметры браузера; правила работы такого сайта должны описываться его собственной политикой. Не следует понимать отсутствие телеметрии расширения как отсутствие любых веб-запросов при переходе по ссылкам.

Согласие и управление

Тема и локальный анализ содержимого Seller не включаются без принятого в этом браузере согласия. Его даёт только нажатие «Согласен, включить тему» в popup или на странице расширения. Сохранённый режим темы, установка или обновление расширения сами по себе не дают согласия.

На странице расширения доступна кнопка «Отозвать согласие». Она удаляет локальный флаг согласия, останавливает оформление и анализ страницы. Для повторного включения требуется снова явно принять согласие.

Хранение

Анализируемое содержимое страницы не сохраняется расширением после обработки. Тема хранит временные признаки оформления в DOM открытой страницы; перезагрузка страницы удаляет их, после чего включённое расширение может применить оформление снова.

Настройки темы можно изменить в popup или на странице расширения. Выключение темы не удаляет сохранённые предпочтения. Локальное хранилище удаляется при удалении расширения; управление синхронизированными данными выполняется средствами Chrome и аккаунта Google. Мы не обещаем удаление данных из инфраструктуры Google простым выключением темы.

Обработка ограничена применением и настройкой тёмного оформления. BLACK OWL Tech не продаёт данные кабинета, не использует их для рекламы, кредитных решений или составления профилей и не предоставляет людям доступ к ним через расширение. Использование информации, получаемой через API Chrome, соответствует Chrome Web Store User Data Policy, включая требования Limited Use.
